## 协作约定（用户明确要求，优先级最高）

1. **要数值就直接给单值**：价格 / 数量 / 阈值直接判断给最合适的那个，不给范围、不反复追问。
   信息不足先写必要假设再给数，数后标「**由助手给定值**」。落地 `docs/04` §27 + `tests/test_single_values.py`。
2. **任务分解必须具体到可执行动作**：不接受「需要你确认」「请你补充数据」。
   每项给四件：为什么只能你做 / 具体在哪儿（菜单路径、报告名、字段名）/ 回我什么格式 / 不做的后果。
3. **能自己验的一律自己验，不交给用户**（11-23 21:10 用户明确要求，优先级仅次于第 1 条）：
   跑命令、核对数字、看输出、重跑门禁全部由代理执行，并把真实输出贴回来。
   只有两种情况才交出去：① 需要**外部事实**（供应商答复、后台报表读数、他的报价）；
   ② 敏感/破坏性操作（删库、发布、动生产）。交出去时必须写成「照着做就能做」：
   完整命令 + 预期输出里的**那个数** + 数不对说明什么；禁止「跑一下确认」这类话。
4. 需人工介入的台账固定在 `docs/07-需人工介入清单.md`，编号 `H1…Hn`。新增追加、完成划掉但不重排；
   提到人工依赖只引用编号。
5. 结论先行 + 表格对比；每个决策给「为什么这么选 / 为什么不选另一种」。
6. 数字必须可复现：一个指标对应一条命令，默认 `scripts/check.py`（Git Bash 里常没有 `make`）。

## 数据纪律（不可放宽）

- 参数状态只有 `draft` / `verified`；`verified` 要 来源 + 生效日期 + 核实日期（写进 CHECK）。
  查不到就留 draft，**禁止「大概 15%」这类印象值**。AI 代填的数一律标「设定 / 非核实」+ 替换条件。
- 缺失 ≠ 通过：合规未覆盖或未核实一律 `unknown`，不得降级 `clear`。
- **六项成本不填是 `None` 不是 0**（H17，`docs/04` §31）：`inbound_freight` / `duty_rate` /
  `return_rate` / `returns_handling_fee` / 两个损失比例。漏填按 0 计入但记 `missing_inputs`
  → 算出来是**上界**，上界达标不得称 PASS（→ NEED_MORE_INFO），只有上界不达标才保留 NO_GO。
  「缺不缺」按口径判断：DDP 下头程/关税不算缺、退货率为 0 时三项退货参数不算缺。
  护栏 `tests/test_profit_guardrails.py`（8 条）。
- **`Candidate` 也不带默认值**（H24）：缺头程/退货率 → 上界，且 `max_cogs` / `min_price` /
  广告空间线两个 / `cogs_reduction_pct` **一律不给**（上界反解偏高，按它开口必亏）。
  硬缺（duty/售价/采购/FBA → 判不了）vs 软缺（→ 上界）写在 `admission.SOFT_MISSING_HINTS`；
  `stress_test` 拒绝上界。**单台 `screen` 不补默认值**，批量注默认但声明「粗筛」。
- `CostProfileInput.fba_fee` 没有默认 0：缺它必须给 `product_class` + `ship_date`，否则 422。
  未知 FBA 是**三值判断**（乐观端不达标→FAIL / 保守端达标→PASS / 跨阈值→NEED_MORE_INFO），
  点值永远取最贵档。包络宽不是缺陷，用假数变窄才是。
- 不爬亚马逊前台；只采信官方站点（Seller Central / USITC / CBP）。

## 回复 → 动作（2026-11-24 10:20）

- `scripts/db.py reply`：吃四个事实（箱规能/不能/没答、受限原因、他的报价、`--firm`），
  出一种动作 + 全部数字 + 可直接发的话术。**退出码即结论**：0 有动作 / 1 先放 /
  3 还在等对方 / 2 输入不成立。判定全在 `domain/reply.py`，七动作：
  `reask_box` / `reask_blocker` / `open` / `accept` / `counter` / `reprice` / `drop`。
- **优先级**：箱规未答先问不报价 → 「改不了」没说原因先问原因（这一问值 $2.00/件，
  B 上限 13.719 → A 上限 15.732，而 B 档压价空间是 $0）→ 才判价。让步按**本轮报价**算。
- **`firm`**（咬死不放）是 `reprice` 的唯一现实入口：$15.80 让步 0.4% 但不再让 →
  券后价 $64.99。没有它，提价几乎不可能触发（超带时涨价需求普遍 >8%，上限 5%）。
- **话术里不许带价**：上一版「做得到的话 $15.00」会被回成「箱规改不了、$15.00 行」，
  那是 B 档 **12.46%**。一次只谈一个变量。
- `NEGOTIABLE_DROP_PCT=15%` / `PRICE_HIKE_MAX_PCT=5%` 是**助手给定值**（3 个案例，
  非分布）；有 3 次以上真实让步记录后替换。
- 入口测试必须 `--db <隔离库>`（`app_db_file`）：`--sku` 读的 `data/app.sqlite3`
  在 .gitignore，直连会让干净克隆四条全红。
