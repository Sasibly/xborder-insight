## 批量准入 --csv（11:35，§19.3）

`db.py screen --csv` 支持一张候选表进、三组结论出（有空间 → 还判不了 → 做不成）。

关键设计：**三种「空」必须分开**
- 单元格留空 → None → 该行 need_info（「我不知道」，候选常态）
- 写了但解析不了 → 报行号并跳过（「写错了」，当成不知道就永远发现不了）
- 整列缺失 → 抛错退出码 2（「表结构不对」，逐行报会得到一片 need_info）

列名大小写/下划线/空格不敏感，中英都收（price/售价、duty/关税、fba占比）；
金额可带 $ 与千分位，比例可写 `23.7%` 或 `0.237`；fba 优先于 fba_ratio。
退出码优先级 2 > 3 > 1 > 0（2 = 这一批统计不可信了）。
示例表 `data/candidates/example.csv` 就是五台，与 §17 表逐台一致。

## 供应商规格这组的互校（11:55，docs/04 §20）

用户答 B 组来源=**供应商规格书**，并要求「填入」。填之前先做互校——来源本身不定案，
供应商规格书既可能写外箱也可能写产品尺寸。

**判据（不需要知道哪套真）**：箱包着机，只能更大更重。`package.compare_packaging` 四形态：
box_vs_unit / contradiction_same_box（三边同、重量差）/ contradiction_weight（更大反而更轻）/
indistinguishable。容差按**体积比 2%**，不按单边差（三条边各差 1% → 体积差 3%，按单边判会造假矛盾）。

**五台结果**：净化器 B 体积 33.4%、轻 9.24 lb → **B 是裸机**；水壶 20.6%、−1.71 → 裸机；
咖啡机 100%、+1.48 → 矛盾；扫地机 99.6%、+14.80 → 矛盾；饮水机单套。
→ **没有一台能把 B 当彩盒**。强行换：净化器 −7.64%→+7.96%（+15.6 点）、水壶 →+2.77%，
都是假的好消息，费率表不报错。
