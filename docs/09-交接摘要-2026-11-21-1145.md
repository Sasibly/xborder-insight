### 2.2 关键结论（可直接引用，均已复核）

1. **大件费率是 4/6 品类的主路径，不是边缘需求。** 12 台在售机型中 6 台超出 18×14×8：桌面净化器最短边 10.2/8（超 27.5%）、半自动咖啡机次长边 14.17/14（**只超 1.2%**）、1.7 L 水壶最短边 8.27/8（**只超 3.4%**）、带基站扫地机 13.66/8（超 70.8%）。`docs/07` H11 与 README 原写「6 个品类都是标准尺寸」，**已证伪并更正**。
2. **类别差 18.8–25.9%**：同档 large_standard 8–12 oz，非服装 $4.20 / 危险品 $4.99（2026 非旺季）。
3. **计费重量 ≠ 实重**：实重 2 lb + 18×14×8 → 体积重 14.5 lb = 232 oz，按实重报价**少算 $5.11**。
4. **「装得进 18×14×8」是排除项，不是收窄项**：只排除大件，标准尺寸内部体积重仍按 14.5 lb 算。要收窄必须给三边或体积上界。
5. **费率期按发货日期落哪个闭区间，不按年份或 `season` 字面值**：2026 旺季算到 2027-01-14，2027 旺季官方未发布。
6. **含锂是 SKU 级事实，不是品类级**：宠物饮水机同品类既有无线泵带 48 h 备份电池款（`dangerous_goods`），也有 DC 5V 直供款（`non_apparel`）。
7. **分歧不取均值**：同品类两台机型结论相反 → `DIVERGENT`，只能实测；裕度 <5% 单独标 tight（18×14×8 的 5% = 0.9 / 0.7 / 0.4 英寸，小于纸箱公差）。

### 6.1 关键常量与判定（`src/xborder_insight/domain/package.py`）

```python
#: 体积重除数（英寸³ → 磅）。官方用 139，不是 166（166 是部分承运商的口径）。
DIM_WEIGHT_DIVISOR = 139.0

#: 大号标准件的三边上限，**按长度降序**：最长 ≤18、次长 ≤14、最短 ≤8。
STANDARD_MAX_DIMS_IN = (18.0, 14.0, 8.0)

#: 小号标准件的单位重量上限。这一档**不取体积重**。
SMALL_STANDARD_MAX_OZ = 16.0

#: 大号标准件的计费重量上限（20 lb）。超过即不属于标准尺寸。
LARGE_STANDARD_MAX_OZ = 20.0 * 16.0

#: 重量区间的下界。费率表不接受 0 重量，用 0.1 oz 代表「最轻的那一档」。
MIN_WEIGHT_OZ = 0.1

_EPS = 1e-9


def dimensional_weight_oz(dims_in: tuple[float, float, float]) -> float:
    """体积重（oz）= 长 × 宽 × 高 ÷ 139 × 16。"""
    length, width, height = (float(v) for v in dims_in)
    return length * width * height / DIM_WEIGHT_DIVISOR * 16.0


def standard_edge_violation(
    dims_in: tuple[float, float, float],
) -> tuple[int, float, float] | None:
    """检查三边是否都装得进 18×14×8。

    返回 `(第几长边(1/2/3), 实际值, 上限)`；全部满足返回 None。
    先按长度降序排，再逐位比对——不排序的话，18×8×14 这种写法会把
    次长边 14 拿去和上限 14 比、最短边 8 拿去和上限 18 比，判成通过。
    """
    ordered = sorted((float(v) for v in dims_in), reverse=True)
    for index, (value, limit) in enumerate(zip(ordered, STANDARD_MAX_DIMS_IN), start=1):
        if value > limit + _EPS:
            return index, value, limit
    return None


_PRODUCT_CLASS_BY_BATTERY = {True: "dangerous_goods", False: "non_apparel"}
```

`classify(facts: PackageFacts) -> PackageClass` 的三条分支（实重缺失 / 实重 ≤16 oz / 实重 >16 oz）全量见文件，要点：

- 没给尺寸也未声明「能否装进」→ `InputInvalid`（这是判断题，不是估算题）
- 声明装不进 → `ParamUnverified`（大件费率未录，禁止用标准件顶替）
- 没给三边也没给体积上界 → 体积重按 18×14×8 装满取上界 **14.5 lb**，并附 warning
- 实重 ≤16 oz → 小号与大号**两段都保留**（小号三边上限未核实，见 H13），并附 warning

### 6.7 H2 四列口径（实测时照这个填）

| 列 | 怎么判 | 填错的后果 |
| --- | --- | --- |
| 含锂电池 | 产品本身或包装内是否含**锂离子 / 锂金属 / 锂聚合物**电池。含 → 危险品表；不含 → 普货表 | 含锂按普货填，每件少算约 $1.16，响应里看不出来 |
| 实重上界 | 包装后总重（含外箱与填充），可以给上界 | 给裸机重量会判小一档，费率低 $0.5–1 |
| 能否装进 18×14×8 | **三条同时满足**：最长 ≤18、次长 ≤14、最短 ≤8（英寸） | 任一条超出即落大件/超大件，费率未录，只能 503 |
| 包装体积上界 | 长×宽×高（英寸³）的粗略上限，不知道就写「一个鞋盒 ≈ 400」 | **最容易漏。** 只填「装得进」不填体积，费用上界按 14.5 lb 算，很多品判不了 |

实测样例（售价 $59.99、危险品、实重 ≤2 lb、2026 旺季、报价 $18、佣金 15%）：

| 你给到哪一步 | 毛利率区间 | 能不能定论 |
| --- | --- | --- |
| 只给「装得进 18×14×8」 | 12.9% – 24.9% | 判不了（跨 15%） |
| 再加「体积 ≤400 in³」 | 20.0% – 24.9% | 可判：毛利项通过 |
| 换成精确三边 12×10×6 | 20.0% – 24.9% | 同上，且能给点位 |

**A 级第四列不是可选项。**
